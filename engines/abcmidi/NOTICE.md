# abc2abc runtime

MusicLab uses only `abc2abc` from abcMIDI for textual ABC transposition.

- abc2abc version: 2.22 (April 30, 2024)
- binary distribution: `abcmidi_win32_mingw64.zip` (June 6, 2026 build)
- source: https://github.com/sshlien/abcmidi
- binary package: https://ifdo.ca/~seymour/runabc/abcmidi_win32_mingw64.zip
- license: GNU GPL version 2 or later

The executable is downloaded and checksum-verified by
`install-abcmidi-runtime.ps1`; it is not tracked in Git.
